这版补齐 AOD 直接指纹解锁的动画，修好解锁后按 Home 时桌面闪一下的问题，并让 Home 开关抽屉走满刷新率。

## 适用系统

- 已在 Android 17 构建 `CP3A.261005.005`（Pixel 10 Pro）配 Action Launcher 53.0 上验证。
- AOD 直接指纹解锁的补丁只在已验证的系统构建与 Action Launcher 53.0 上生效；其他组合下模块会跳过这一项，其余修复照常加载。系统或 Action Launcher 升级后请先确认问题是否还在。

## 新功能

- **AOD 直接指纹解锁的动画补齐**：在 AOD 上直接指纹解锁时，补齐系统本来会跳过的解锁动画，不再从黑屏硬切到桌面。只命中已验证的唤醒组合，`mode6 + LIFT` 这一组合尚未在真机上实际命中过，仍按等待观察处理。
- **高刷新率下的抽屉动画**：Home 开关抽屉时向系统请求 120Hz，避免系统停在 60Hz 静止速率出帧。该项在真实掉帧状态下的复测未完成，目前依据是持续使用未再出现卡顿。

## 问题修复

- **解锁后按 Home 桌面闪一下**：解锁后立刻按 Home 打开抽屉时，会重放一次桌面显现动画，表现为图标整体消失再淡入。现在只有真正从其他应用回到桌面才做这项修复，原地按 Home 与返回键都交回原生行为。
- **返回键不关抽屉**：Action Launcher 53.0 在 Android 16 以上跳过旧返回逻辑，按返回键会直接回桌面；现在转交给它自己的返回处理。
